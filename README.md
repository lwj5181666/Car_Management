# Car Management · 车辆管理系统

车辆装卸货登记与运输统计的 Windows 桌面程序（课程设计作品）。

把微信里的磅单截图拖进窗口，程序自动识别车牌号、时间、净重和司机信息；每天的数据以 CSV 保存在本地，月底可以按车牌统计运输次数并导出报表。

## 功能

- **磅单识别录入**：装车磅单、卸货计量单两种版式，识别结果先弹窗核对，确认后入库
- **当日信息表**：11 个字段，装车与卸货自动合并成一行，状态自动更新（准备 / 装车 / 卸货 / 完成）
- **任意关键词查询**：车牌、省份简称、司机姓名、电话、身份证号、日期都能搜
- **运输统计**：按时间段汇总明细，按车牌统计运输次数，跨天同一趟自动去重
- **司机身份登记**：身份证号为主键，可从历史记录一键导入
- **导出**：当日表导出 xlsx，统计表导出明细 / 汇总 CSV
- **自动保存**：每 60 秒自动保存，写盘前备份，保留最近 20 份

## 技术栈

| 层 | 选型 |
|---|---|
| 界面 | PySide6（Qt 6），QTableWidget + 自定义委托 |
| 文字识别 | RapidOCR 1.2 + PP-OCRv3（ONNX Runtime，本地推理） |
| 数据存储 | CSV（每天一个文件，UTF-8 BOM） |
| 导出 | openpyxl |
| 打包 | PyInstaller（onedir，免安装） |

主程序约 1280 行，统计程序约 370 行。

## 从源码运行

```bash
cd 源码
pip install -r requirements.txt
python 车辆管理系统.py
```

## 打包

双击 `源码/打包.bat`，产物在 `dist/` 下（onedir 形式，两个 exe + 两个依赖目录）。

## 数据说明

```
数据/
  每日信息/YYYY-MM-DD.csv    每天一个文件，11 列
  司机身份登记表.csv
  备份/                      每次写盘前的历史备份
```

程序不联网、不注册，所有数据只留在本机。换电脑时把整个文件夹拷过去即可。
